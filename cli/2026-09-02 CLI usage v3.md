# `LocalSend` для командной строки macOS

Программа отправляет один файл или один текст на устройство `LocalSend` с точным именем `RUGM0Q3RJ0`. Выбор другого получателя отсутствует.

## Сборка

```bash
cargo build --manifest-path cli/Cargo.toml --release --locked
```

Исполняемый файл будет создан по адресу `cli/target/release/localsend-cli`.

При необходимости установите его в пользовательский каталог:

```bash
install -d "$HOME/.local/bin"
install -m 755 cli/target/release/localsend-cli "$HOME/.local/bin/localsend-cli"
```

## Использование

Отправка файла:

```bash
cli/target/release/localsend-cli /полный/путь/к/файлу
```

Отправка текста:

```bash
cli/target/release/localsend-cli --text 'Текст сообщения'
```

## Dropzone 5

Сначала установите собранную программу в пользовательский каталог:

```bash
install -d "$HOME/.local/bin"
install -m 755 cli/target/release/localsend-cli "$HOME/.local/bin/localsend-cli"
```

Затем откройте пакет действия:

```bash
open "cli/dropzone/Send to RUGM0Q3RJ0.dzbundle"
```

Dropzone предложит добавить действие `Send to RUGM0Q3RJ0` в сетку. Действие работает следующим образом:

1. Перетаскивание одного или нескольких файлов отправляет их последовательно.
2. Перетаскивание текста отправляет этот текст.
3. Нажатие на действие отправляет изображение или текст из буфера обмена.
4. Результат или ошибка показываются средствами Dropzone.

Нужна версия Dropzone 5 с сайта разработчика или из Setapp. Версия из Mac App Store не запускает пользовательские действия вне песочницы.

После повторной сборки программы обновите установленный исполняемый файл:

```bash
install -m 755 cli/target/release/localsend-cli "$HOME/.local/bin/localsend-cli"
```

## Приложение для Dock

Приложение Automator `Send to RUGM0Q3RJ0.app` делает то же, что и действие Dropzone, и закрепляется в Dock. Сборка и установка в `~/Applications`:

```bash
cli/automator/build.sh
```

Другой путь установки передайте первым аргументом. Затем перетащите приложение из `~/Applications` в Dock. Приложение работает следующим образом:

1. Перетаскивание одного или нескольких файлов на значок отправляет их последовательно.
2. Нажатие на значок отправляет изображение или текст из буфера обмена.
3. Об успехе сообщает уведомление, об ошибке – окно с текстом ошибки.

Перетаскивание текста на значок в Dock macOS не поддерживает. Логика приложения находится в `cli/automator/send.applescript`. После ее изменения снова запустите `build.sh`.

Обе машины должны находиться в одной локальной сети. На целевой машине должен быть запущен `LocalSend`, а имя устройства в его параметрах должно быть равно `RUGM0Q3RJ0`.

Программа может работать одновременно с графической программой `LocalSend`. Для соединения она разрешает имя `RUGM0Q3RJ0.local` через `mDNS` и обращается к `HTTPS`-порту 53317. Временный сервер для обработки отмены использует первый свободный порт от 53318 до 53327. Передача не зависит от входящей регистрации через `multicast`.

## Автоматический прием

При первом запуске целевая машина может запросить ручное разрешение на прием. Программа один раз создает сертификат отправителя в `~/Library/Application Support/localsend-cli/identity.json` и использует его при следующих запусках.

После первой передачи добавьте `LocalSend CLI` в избранные отправители на `RUGM0Q3RJ0` и включите быстрое сохранение для этого отправителя. Последующие передачи смогут завершаться без ручного разрешения, если параметры приема `LocalSend` это допускают.

Не удаляйте `identity.json`, если целевая машина уже распознает отправителя.

## Проверка получателя

В программу встроен проверенный SHA-256-отпечаток HTTPS-сертификата `RUGM0Q3RJ0`:

```text
CA6C3E0CDA4B31BDE63E171C8D548D00E658D15CAAD8E7DC8719CF0AD3A8DA12
```

Устройство с тем же именем, но другим сертификатом будет отклонено. HTTP не поддерживается.

После переустановки `LocalSend` сертификат может измениться. В таком случае сначала проверьте новый отпечаток на целевой машине, затем обновите `TARGET_FINGERPRINT` в `cli/src/lib.rs` и снова соберите программу. Файл `identity.json` удалять не нужно.

## Ограничения

Одна команда передает один объект. Подготовка получателем ограничена одной минутой, загрузка – 30 минутами. Программа возвращает ненулевой код, если получатель отклонил файл, отменил передачу, сменил сертификат, не разрешается через `mDNS` или не отвечает по `HTTPS`.
